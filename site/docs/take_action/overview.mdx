# Take Action

:::tip[The question this area answers]
**What can I do today that is not just posting online?**
:::

The catalog of things a citizen can actually do this week, each one worth points and each one checkable.

## What this area covers

- The action catalog across five tracks (challengers, communications, organizing, lawmaking, participation).
- What each action is worth, from adding a video at 5 points to a challenger winning at 5,000.
- How an action is logged with a URL and a description as evidence.
- Peer reporting.
- Anti-gaming..

## What it deliberately leaves to other areas

- What the points become — that is karma..
